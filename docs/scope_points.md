# Scope points

Scope points is a intuitive way to place measurement points and spans directly 
into prompt text so the output SAEs are measurable.

This allows you to place probe points, `<:>`, which mark the token immediately
before the mark, and probe spans where `<:` and `:>` mark the beginning and end
of the span respectively.

> The most important local food to try when visiting Chicago<:>, is their famous 
> <:Chicago-style hot dog:>.
